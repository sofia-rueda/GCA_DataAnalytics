# GCA_DataAnalytics

## Project Portfolio Overview

This repository features a curated set of data analytics projects showcasing my skills in data cleaning, visualization, statistical testing, and storytelling.

### Folder Structure

* [`Milestones/`](./Milestones)
  Projects completed as part of the **Global Career Accelerator Program – Data Analytics Track**. These projects were built around structured case studies and business scenarios, designed to simulate real-world analyst work.

* Side Projects
  Folders such as [`Buzzfeed/`](./Buzzfeed), [`Formula 1/`](./Formula%201), [`Fresh Monster/`](./Fresh%20Monster), [`NationalPark/`](./NationalPark), [`Spotify/`](./Spotify), [`Terracotta/`](./Terracotta), and [`Uber/`](./Uber) represent independent projects I developed during **Live Labs** and **Skillbuilder lessons**. These were self-directed—no prompts were provided—and reflect my initiative in exploring diverse datasets and business contexts.

### Featured Projects

#### [`Milestones/`](./Milestones)

* **ASICS Referral Campaign Analysis** – Measured the impact of a customer referral program on new users and repeat purchases.
* **H\&M A/B Test – Email Subject Line** – Assessed subject line performance using open rates and statistical significance testing.
* **BART Ridership Analysis** – Explored transit usage trends to support better scheduling for Bay Area Rapid Transit.
* **DoorDash Delivery Performance** – Identified inefficiencies in delivery times by cuisine and region.
* **Warby Parker Landing Page Test** – Evaluated web design effectiveness through A/B testing and user survey data.
* **YouTube Trending Content Study** – Uncovered trends in viral video characteristics across categories and engagement levels.
